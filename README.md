# Nivel Cero

Código de https://nivel-cero.github.io/, una guía en español sobre hardware y homebrew de consolas.

## Verla en local

Hace falta [Hugo](https://gohugo.io/), versión 0.167.0.

```
git clone --recurse-submodules https://github.com/nivel-cero/nivel-cero.github.io.git
cd nivel-cero.github.io
hugo server
```

Después, abre http://localhost:1313/.
